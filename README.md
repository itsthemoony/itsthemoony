### 👨‍💻 About me

I'm a **full-stack software engineer with 5+ years of production experience**, building across **web, mobile, and AI-powered SaaS**. I work end to end: understanding requirements, designing in Figma, developing secure APIs and polished interfaces, writing tests, and shipping reliable software.

Before focusing on engineering, I worked full-time as a **Business Analyst**. Writing user stories, acceptance criteria, and **1,000+ test cases** taught me to think about the user, edge cases and measurable outcomes before writing code.

I build with **Claude Code, Codex, and Cursor**, while personally owning the architecture, security decisions, code review, and verification. AI accelerates the workflow; engineering judgment remains the quality gate.

- 🎨 **Product & UI/UX:** Figma, requirements, user flows, and reusable design systems.
- 🌐 **Web:** Next.js, React, TypeScript, and Tailwind CSS.
- ⚙️ **Backend:** Node.js, Express, PostgreSQL, Supabase, REST APIs, authentication, and multi-tenant security.
- 📱 **Mobile:** Flutter, Dart, BLoC/Cubit, Clean Architecture, and Swift/SwiftUI.
- 🤖 **AI systems:** LLM integration, RAG, pgvector, MCP servers, document extraction, and human-in-the-loop review.
- 🧪 **Quality:** Unit, widget, integration, and end-to-end tests; CI/CD and maintainable architecture.

### 🚀 Projects

#### 🧾 Paperlane — AI document-processing SaaS

Designed and launched a multi-tenant platform for receipts, invoices, and insurance claims, with:

- **LLM extraction with source-line evidence** and deterministic checks (including VAT, IBAN, and duplicates).
- **Human-in-the-loop review**, confidence-based workflows, and tenant isolation.
- **RAG copilot** with hybrid retrieval, pgvector embeddings, and verified citations.
- **MCP tools**, secure REST APIs, signed webhooks, and row-level security.

`Next.js` · `React` · `TypeScript` · `Express` · `PostgreSQL` · `Supabase` · `pgvector` · `Vitest` · `Playwright`


#### 🌿 [VYRA — NASA Space Apps](https://github.com/NSP-BlueHorizon/vyra-mobile)

A health-aware navigation prototype using Mapbox and NASA Earth observation data. Built in **48 hours** and ranked **top 10 of 72 teams** at NASA Space Apps Istanbul.

`Flutter` · `Mapbox` · `BLoC` · `REST APIs`

#### 🛸 [Rick & Morty — BLoC Explorer](https://github.com/itsthemoony/rickandmorty_bloc)

A production-style Flutter reference project demonstrating feature-first architecture, BLoC state management, dependency injection, typed error handling, and persisted UI state.

`Flutter` · `Dart` · `BLoC` · `get_it` · `fpdart` · `hydrated_bloc`
